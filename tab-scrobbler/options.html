Tab Scrobbler

Scrobbles what you play in the SiriusXM and Apple Music web players to Last.fm.

Last.fm account

  1. Create a free Last.fm API account at last.fm/api/account/create. Any application name works; leave the callback URL empty.
  2. Paste the API key and shared secret it gives you below.
  3. Click Connect and approve access in the Last.fm tab that opens.

Radio and other tracks with no known length

SiriusXM does not say how long a song is, so a track counts once you have listened this long (30–240). Apple Music tracks use the usual Last.fm rule: half the track or four minutes, whichever comes first.

Your API key, secret and Last.fm session are stored only in this browser profile, and track details are sent only to Last.fm.
